# Advanced tasks

Enable **Advanced task lists** and open its activity-rail view. Set **Path** to
`plugins/Advanced tasks.md`, **Tag** to `glider`, and **Status** to **All**.
Leave **Due** unfiltered to see both dated and undated tasks.

Toggle a checkbox with Space or a pointer; only its Markdown marker changes.
Choose a task's note title to return to its source and enclosing heading.

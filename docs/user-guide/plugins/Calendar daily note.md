# Calendar daily note

Today in this fictional notebook: fold a paper glider and record one change to
its wings.

Enable **Calendar and daily notes**, open **Calendar**, and choose
**Daily and dated** under **Dates**. Navigate to October 2026 and select the
14th. Open this note from the listed notes; navigation alone creates nothing.

The `type: daily` marker keeps this note out of **Created** and **Last updated**,
even though its filename is not a date. Compare the
[ordinary dated note](<Calendar dated note.md>).

This sample deliberately lives in `plugins/`, not the default `Daily/` folder.
**Create daily note** targets the separately displayed daily-note path, normally
`Daily/2026-10-14.md`; it is not needed to open this sample.

# Emoji practice

Enable **Emoji picker** and keep this note editable in Rich or Source mode.
Place the caret after a practice label below, then press `Command-Shift-E` on
macOS or `Ctrl-Shift-E` on Windows/Linux. Search for `smile`, choose a result,
and use Undo to remove it.

With **Shortcode suggestions** enabled, type `:sm` after a label and explicitly
accept a suggestion. Escape keeps the typed text. Existing shortcodes are not
converted automatically, and typing inside code does not offer suggestions:

```text
:smile: stays literal here
```

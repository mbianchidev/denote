# Git workflow

This is a manual local-history exercise, not a setup script. **Do not initialize
a repository in the Welcome vault.** Reading this file runs no Git command.

1. Open a separate empty practice folder as a vault, for example
   `Paper glider sandbox`. Create `Practice.md` there and copy the practice text
   below into it.
2. Enable **Git vault versioning** in **Settings -> Plugins** after reviewing
   its permissions. Keep **Automatic commit interval** at `0` and
   **Push automatic commits** off. Configure a local commit identity if needed.
3. In that practice vault's Git view, check the selected scope before explicitly
   choosing **Initialize repository**. Initialization happens only on your action.
4. Stage only `Practice.md`. Use **Commit**, not **Commit and push**. Turn
   **Sign commit** off for this unsigned local exercise.
5. Change `broad wings` to `narrow wings`, save, and choose **Open diff**.
   Stage that file and make a second local commit. Select either commit in
   **History** to inspect its recorded change.

No remote, account sign-in, fetch, pull, push, automatic commit, or branch
deletion is needed. Disabling the plugin leaves the practice notes and their
local history intact.

## Practice text

The paper glider has broad wings.

Its next trial starts from the same shelf.

# Note graph

This fictional paper glider begins with a [wing sketch](<Graph sketch.md>).
The sketch links onward to the supplies note, making a three-note chain.

Enable **Note graph** and open its activity-rail view. Choose **Global**, set
**Folder** to `plugins` and **Tag** to `graph-example`, and leave
**Connections** unfiltered. Only the three tagged sample notes remain.

Keep this note active, choose **Local**, and compare **Depth** `1` with `2`.
Depth 2 reaches the supplies note through the sketch. **Open Note graph in a
tab** gives the map more space; choosing a node opens a separate note tab.
**Show keyboard note list** provides the same navigation without a pointer.

The connections come only from ordinary Markdown links, not special metadata.

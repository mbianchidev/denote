# Present and return

Choose **Present**. Use arrows, Page Up/Down, Home/End, and Escape.
Space on the slide plays or pauses. **P** pauses immediately.

Try the positive interval, Loop, Restart, and Stop controls. Return to note:
the original Markdown, frontmatter, and separators remain unchanged.

# Plugin examples

These small, invented examples are ordinary vault files. Choose a plugin in
**Settings -> Plugins**, review its permissions, and enable it yourself before
trying its view. Opening an example never installs or enables a plugin.

| Plugin | Open | Try |
| --- | --- | --- |
| Calendar and daily notes | [Daily note](<Calendar daily note.md>) and [dated note](<Calendar dated note.md>) | Find both on October 14, 2026; compare daily and activity views |
| Emoji picker | [Emoji practice](<Emoji practice.md>) | Insert Unicode with the picker and accept a shortcode suggestion |
| Git vault versioning | [Git workflow](<Git workflow.md>) | Follow a manual local-history exercise in a separate practice vault |
| JSON and YAML viewer | [JSON](<Structured data.json>) and [YAML](<Structured data.yaml>) | Expand nested values, inspect the alias reference, then compare the unchanged Raw source |
| Kanban boards | [Kanban board](<Kanban board.kanban.md>) | Move cards between three columns with the pointer or keyboard |
| Mermaid diagrams | [Mermaid flow](<Mermaid flow.md>) | Render a small decision loop in Rich view |
| Note graph | [Note graph](<Note graph.md>) | Explore three linked notes with a tag filter and Local depth |
| Advanced task lists | [Advanced tasks](<Advanced tasks.md>) | Filter open/completed tasks, tags, paths, and due dates |
| Reminders | [Reminder targets](<Reminders.md>) | Link a local reminder to the note, a heading, or a Markdown task |

Disable a plugin at any time; the files remain. Git is a written, opt-in
exercise: do not initialize a repository in this Welcome vault. No sample
contains an executable setup script or configures a remote.

The catalog's **Reference plugin** is a developer-only SDK/lifecycle fixture,
not a user workflow, so it has no Welcome example.

New example sets add only their missing paths once, including to older Welcome
vaults. Existing files keep their bytes. Encrypted vaults wait for unlock and
receive ciphertext. Deleting an already-applied example does not restore it on
the next launch.

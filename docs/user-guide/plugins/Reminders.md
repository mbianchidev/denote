# Reminder targets

Enable **Reminders**, open this note, then choose **Reminders** in the activity
rail. Create a reminder for the whole note, the **Pack the field kit** heading,
or either synthetic task below.

## Pack the field kit

- [ ] Charge the weather sensor
- [ ] Print the trail checklist

The example never creates a reminder by itself. Pick a future local date and
time, then try **Open note**, **Snooze**, and **Dismiss** from the Reminders
panel. Reminder metadata stays local and this Markdown remains unchanged.

# Text styling practice

Enable **Text highlighting and coloring** in **Settings → Plugins** first.
Opening this file never enables it or changes the source.

=red=Review this invented sentence=red= before publishing.

Keep meaning in words, not only in color. Here is
=blue:text=an example foreground style=blue:text= with an underline and a written
color name in its tooltip.

Select a plain phrase on this line, choose **Text style**, then a named
highlight or foreground color. Switch to **Source** to inspect the exact
delimiters. **Styled excerpts → Clear** removes one extension without
reformatting surrounding Markdown.

Search this vault with **Filters → Notes with highlights** and an empty query.
Each indexed highlight is a separate navigable result. Disabling the plugin
leaves every word and delimiter intact.

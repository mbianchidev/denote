# Time tracking practice

Enable **Time tracking** in **Settings → Plugins**, then open its activity-rail
panel. Starting, pausing, or stopping clocks never changes this file.

## Try the clocks

1. In **Timer**, choose **Start timer**, pause it, then reset it.
2. In **Countdowns**, name a ten-second countdown **Synthetic break**.
   Clear the default minutes, enter ten seconds, and clear **Repeat alarm sound**
   to skip the repeating in-app tone. Start it, then dismiss its banner when it
   expires. System notification sounds still follow your system settings.
3. In **Alarm**, create **Synthetic check** at a future date and time. Review
   the displayed time zone. Try five-minute snooze, dismissal, or deletion.
4. To try repeating sound, explicitly select **Repeat alarm sound**. Use
   **Enable alarm sound** after restart if needed; **Stop sound** mutes the
   current occurrence without dismissing its banner.

Denote must be running to issue alerts. It catches up after sleep or restart;
there is no closed-application alarm service. Clock names and schedules live
outside vault encryption. Global alert controls remain available while locked.

## Track this note

Choose **Notes** while this note is active.

1. Enter **Synthetic planning** as the description and choose **Start timer**.
2. Choose **Pause timer**, wait briefly, then choose **Resume timer**.
3. Open another note. The timer still belongs to this note.
4. Return to **Time tracking** and choose **Stop timer**.
5. Compare **Daily** and **Weekly** totals by note, project, and tag.
6. Choose **Correct session**, adjust elapsed minutes within its start/end
   interval, and explain the change. Inspect **Correction history**.
7. Export CSV or JSON to a location you choose.

To associate the next session with a project, mark a practice folder as a
project and start from a note inside it. This example never marks projects,
starts timers, enables plugins, or writes exports automatically.

Sleep and ordinary application restarts keep running duration clocks. A system
reboot pauses them at the last saved checkpoint so you can review missing time without
trusting a changed wall clock. Session metadata and exports are outside vault
encryption. Disabling asks for confirmation before stopping timers and alarms.
